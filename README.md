## Descripción
Sitio web completo para el Hotel El Rejunte. Incluye vistas para usuarios y administradores, desarrollado con HTML5 y CSS3 puro sin frameworks ni librerías externas.

## Tecnologías utilizadas
- HTML5
- CSS3 (sin frameworks ni librerías externas)

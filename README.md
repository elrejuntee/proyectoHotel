# El Rejunte Hotel — Sitio Web

## ¿Qué es este proyecto?

Este es el sitio web del **El Rejunte Hotel**, un hotel ubicado en Buenos Aires, Argentina.

El objetivo del sitio es permitir que cualquier persona pueda conocer el hotel desde internet: ver las habitaciones disponibles, los servicios que ofrece y ponerse en contacto. Además, cuenta con un área privada para que los huéspedes puedan ver sus reservas y un panel para que el personal del hotel administre las habitaciones.


## ¿Qué páginas tiene el sitio?

### Para cualquier visitante
- **Inicio:** foto principal del hotel, lista de servicios (comedor, piscina, WiFi, gimnasio, traslado) y las habitaciones disponibles con sus precios.
- **Nosotros:** historia del hotel y presentación de los desarolladores de la web.
- **Iniciar sesión:** formulario para ingresar al área privada con correo y contraseña.

### Para huéspedes registrados
- **Mi panel:** el cliente puede ver su información personal, las habitaciones que visitó recientemente y su historial de reservas con fechas y montos.

### Para el personal del hotel
- **Panel de administración:** vista completa del estado de las habitaciones (cuántas están disponibles, ocupadas o en mantenimiento), con buscador, filtros y opción de agregar nuevas habitaciones.

## ¿Cómo ver el sitio en tu computadora?

### Lo que necesitás tener instalado
- [Git](https://git-scm.com/) — para descargar el proyecto.
- [Visual Studio Code](https://code.visualstudio.com/) — el programa donde se abre el proyecto.
- La extensión **Live Server** dentro de Visual Studio Code — para poder ver el sitio en el navegador.

> Para instalar Live Server: abrí Visual Studio Code, hacé clic en el ícono de extensiones (lado izquierdo), busca la extencion Live Server.

### Pasos para abrirlo

**1. Descargar el proyecto**

Abrí una terminal bash y escribí:

git clone https://github.com/adriel1364/proyectoHotel.git


**2. Abrir la carpeta proyectoHotel en Visual Studio Code**

Entra a Visual Studio Code, vas a archivo, abrir carpeta proyectoHotel

**3. Abrir el sitio en el navegador**

Dentro de Visual Studio Code, entrá a la carpeta `maqueta` y abrí el archivo `index.html`. Hacé clic derecho sobre ese archivo y elegí **"Open with Live Server"**.

El sitio se va a abrir solo en tu navegador. Desde ahí podés navegar todas las páginas.

> El sitio es solo una maqueta visual. No requiere internet ni ninguna configuración extra para funcionar.
